## ⚙️ Control de Calidad y Metodología

El desarrollo de esta prueba se ejecutó bajo un flujo estricto de control de versiones en GitHub:
1. Creación de ramas independientes por cada módulo o rol.
2. Commits significativos y descriptivos por integrante.
3. Apertura de **Pull Requests** revisados, comentados y aprobados de forma cruzada por los miembros del equipo antes de ser integrados a la rama `main`.
